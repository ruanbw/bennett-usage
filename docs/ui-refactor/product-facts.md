# Bennett Usage 产品事实（UI/UX 重构基线）

> 核对日期：2026-09-24
> 来源：本地 SwiftUI 源码、README.zh-CN.md、现有产品截图。本文只记录本次设计不变量，不修改产品能力。

## 产品定位

- 原生 macOS 菜单栏应用，聚合本地 AI coding agent 的 Token 与预估费用。
- 目标用户是持续使用 Claude Code、Codex、Gemini CLI、Pi、OpenCode 等工具的开发者。
- 产品承诺：数据本地解析、本地 SQLite 存储、无需 API Key、无需账号。
- 菜单栏常驻显示今日 Token；点击后提供速览、立即同步、打开 Dashboard 与设置。

## 当前功能范围

- 18 个 Agent 数据源或安装状态来源。
- 时间范围：24 小时、今日、7 天、30 天、过去一年、按年。
- Dashboard：总量、费用、输入/输出/缓存、缓存命中率、趋势、工具与模型分布、年度热力图、项目排行。
- 设置：语言、主题、自动刷新、更新检查、Agent 状态、计价与汇率、数据库维护、关于。
- 支持简体中文与英文；支持浅色、深色、跟随系统。

## 平台与窗口尺寸

- 最低系统：macOS 14。
- UI 框架：SwiftUI + AppKit。
- Dashboard 默认内容尺寸：1080 × 740；最小尺寸：960 × 680。
- Settings 内容尺寸：750 × 510。
- 菜单栏弹窗宽度：360 pt。

## 本次重构明确不改

- 不改 Agent 适配器、会话解析、SQLite schema、同步游标或 FSEvents 监听。
- 不改计价引擎、模型价格表、汇率计算与缓存命中统计口径。
- 不改 18 个 Agent 的识别和显示名称。
- 不改产品隐私承诺；任何联网行为仍只限匿名更新检查。

## 当前体验问题假设

1. Dashboard 首屏多个模块权重接近，用户需要自行拼接“总量—变化—原因—下一步”。
2. 时间范围、Agent 筛选、设置入口彼此竞争，工具栏语义不够稳定。
3. 图表颜色同时承担品牌、分类与状态三种职责，语义偶有冲突。
4. 菜单栏弹窗展示数据，但异常、过期与同步状态的优先级不够明确。
5. Settings 的通用页内容少、右侧留白大，导航与内容之间缺少持续可见的状态反馈。
6. 固定窗口尺寸和大量自定义控件可能增加动态字体、键盘导航与辅助功能成本。

## 原型数据说明

- 三套方向稿沿用现有截图中可验证的数据外观，例如今日 327M Token、预估费用 $4.67、Antigravity 185.2M、Oh My Pi 129.1M、Pi Agent 12.6M。
- Dashboard 统一采用现有趋势图与分布图中的 417.3M 作为同一时间范围总量，避免把当前截图中语义不一致的 6.42B 英雄数字带入设计判断。
- 这些数字只用于视觉比较，不代表重新计算后的生产数据。
