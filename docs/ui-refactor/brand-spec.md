# Bennett Usage 品牌与界面资产规范

## 品牌气质

- 关键词：本地、可信、精确、安静、工程化。
- 应避免：游戏化、企业 BI 模板感、通用紫色 AI 渐变、过度圆润的消费级卡片、把每个标题都配图标。
- 品牌承诺优先于视觉炫技：任何新方案都必须让用户更快确认“今天用了多少、为什么变化、数据是否新鲜”。

## 已有可继承资产

- 产品名称：Bennett Usage。
- 当前图形标记：闪光/星芒意象；原型中以克制的四向星芒或首字母标记表达，不重新发明复杂 Logo。
- 18 个 Agent 的显示名称与稳定映射：来自 `AgentFilterBarView`。
- Agent 与模型图表颜色：来自 `ChartPalette` 和 `AppTheme.Agent`，实现阶段应保留映射稳定性。
- 明暗模式与主题运行时切换：已有 `AppThemeMode`、`ThemeColors.swift`。
- 现有界面截图：`docs/screenshots/dashboard.png`、`popover.png`、`settings.png`。

## 视觉资产规则

- 产品是工具型桌面应用，内容主体是数字、状态和图表；不添加与任务无关的装饰图片。
- 图表属于内容必需信息，应使用真实数据驱动；不得用无意义渐变、虚构统计或 Emoji 充当图标。
- 颜色必须具备职责：一种交互主色、若干数据分类色、成功/警告/危险状态色。分类色不应同时承担按钮选中态。
- 圆角不是默认答案：菜单栏弹窗可适度柔和，Dashboard 与 Settings 应根据方向决定采用连续容器还是精密分区。
- 字体优先使用 macOS 系统字。数字启用 tabular figures；代码路径、模型 ID、版本号可用 SF Mono/等宽回退。
- 正文与控件字号必须支持系统动态字体；颜色对比度至少满足 WCAG AA。

## 三大界面共同语汇

### 菜单栏弹窗

- 第一层：今日 Token 与预估费用。
- 第二层：数据新鲜度/异常状态。
- 第三层：最高贡献 Agent 与快速动作。
- 宽度维持 360 pt 左右，避免成为缩小版 Dashboard。

### Dashboard

- 第一视口必须先回答三个问题：总量多少、较基准如何变化、主要原因是什么。
- 时间范围与 Agent 筛选是全局控制，应位置稳定、状态明确，不与页面级设置混在一起。
- 趋势用于回答“何时变化”，分布用于回答“谁在消耗”，项目用于回答“在哪里消耗”；三者不应以同等视觉重量堆在首屏。
- 高频动作不超过三个：刷新、打开完整 Dashboard、设置。危险操作不进入主界面。

### Settings

- 使用平台熟悉的侧栏导航与分组列表。
- 每一项显示标题、必要解释、当前值；不要让用户猜保存方式。
- 数据维护、清理记录等危险操作与普通偏好分区，并提供明确结果反馈。
- 不在窗口内容里重复放置 macOS 原生标题栏已有的关闭按钮。

## 禁止破坏的现有行为

- Dashboard 与 Settings 使用独立窗口，关闭设置不改变 Dashboard 状态。
- 键盘快捷键、菜单栏状态项、更新提示和本地隐私承诺继续工作。
- 所有数据刷新、解析、同步与错误状态必须继续由现有状态对象驱动。
