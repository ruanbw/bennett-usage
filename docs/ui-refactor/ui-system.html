先回答「我今天怎么样」，再允许追问「为什么」。

01

三条结构原则

现状的问题不是信息不够，而是所有信息都在同一音量上说话。重构只做一件事：给信息排序，并且让排序在三个界面上保持同一种语法。

一屏一个结论

首屏第一行必须能被一句话读完。总量、变化、原因三件事在一块连续容器里，其余全部降级。

替换：三张等权 highlight 卡片 → 单条结论带

颜色只做一件事

蓝＝你正在操作的东西；分类色＝数据属于谁；状态色＝数据健不健康。三者互不串用。

替换：图表色同时充当按钮选中态

状态永远可恢复

过期、同步中、部分缺失、解析失败，都必须说明「发生了什么 + 下一步按哪个键」，不出现纯灰空窗。

替换：绿色小圆点 + 静默失败

02

颜色职责与令牌

全部颜色在 :root 定义为 OKLch，明暗两套只切换令牌值。任何界面代码不得出现字面色值。分类色沿用 AppTheme.Agent 现有映射，一个值都不改。

交互色 · 唯一主色

只用于「选择中 / 焦点环 / 主按钮 / 危险操作」。绝不用于表达任何数据。

选中分段、刷新后的主按钮、焦点环。整屏不超过三处。

状态色 · 健康与新鲜度

只用于「进度环 / 同步状态 / 告警条 / 危险操作」。达标用绿，未达标用琥珀，失败用红。

缓存命中率环、数据新鲜度、超期横幅、清理历史记录。

量级色 · 墨色刻度

一切「强弱」都用墨色透明度表达：趋势面积、热力格。不新增第五种色相。

趋势图、热力图、未选中来源的柱子。仪表感来自刻度，不来自彩虹。

弹窗的删除清单

从原稿里拿掉的东西，和拿掉的理由：

第 4 个按钮「打开 Dashboard / 立即同步 / 设置 / 退出」四连排权重相同，等于没有主动作。退出属于系统菜单，弹窗只保留图标行。

主题切换入口设置归设置。弹窗里不出现第二处主题开关。

08

状态矩阵

每个状态都回答三件事：发生了什么、数据还能不能信、下一步按哪个键。禁止只显示「暂无数据」。

LOADING · 首次加载

保留结论带的版式骨架，避免加载完成后布局跳动（CLS = 0）。不显示转圈盖住整页。

EMPTY · 所选范围无记录
30 天内没有使用记录 切换时间范围，或立即重扫本地会话

说明「无记录」而不是「加载失败」—— 空数据是有效结论。

数据已过期 25 分钟。数字仍可用，但可能缺少最新的会话记录。

09

动效、键盘与可访问性

动效 · 只为解释变化

数值变化180ms 线性插值，tabular figures 不跳动。范围切换时数字滚动，不用闪烁。
进度环520ms ease-out 从 0 走到目标值；达标状态切换时颜色 300ms 过渡。
悬停120ms 背景与边框过渡，不做位移与阴影，避免界面「呼吸」。
结论带警告背景与边框 240ms 过渡；不播放抖动，不使用红闪。
窗口出现系统默认缩放动画，不自绘。首屏不做入场编排。
降低动态全部尊重 prefers-reduced-motion / macOS 减弱动态效果。

键盘与对比度

Tab 顺序工具栏 → 范围分段 → 来源筛选 → 图表 → 列表，与视觉顺序一致。
快捷键⌘R 立即同步 · ⌘, 设置 · ⌘⇧D Dashboard · ⌘1–5 时间范围
图表可达性每张图带一行文字摘要（「峰值 3.30B 出现在 09-24」），VoiceOver 不必逐点朗读。
正文对比度正文 ≥ 7:1，次级文字 ≥ 4.5:1，图标与图形 ≥ 3:1（浅深两套均已核验）。
动态字体支持到 .accessibility3；数字容器宽度预留 25% 余量，缩写不截断。
不靠颜色涨跌同时给箭头与文字；来源同时给名称与数值；状态同时给圆点与文案。

「三行之内说完，然后才是仪表盘。」

  1. 每个界面只有一个结论句。Dashboard 是结论带，弹窗是今日 Token，Settings 是数据源与存储状态。句子的数字来自同一套聚合口径。
  2. 颜色是三种工具，不是一支蜡笔。主色只管你正在操作的东西，Agent 分类色只管数据归属，状态色只管数据健不健康；量级一律用墨色刻度。
  3. 拿掉装饰，补上状态。弹窗从四按钮减到一主三辅，Dashboard 从卡片墙压成一条结论带；换来的预算全部投给过期、失败、部分缺失这些真正会发生的时刻。
数据与诚实性说明：全部数值取自本机 usage.db 导出的真实聚合（2026-08-23 → 09-25，共 33 天、8 个来源），未做任何编造或缩放。分类色为 AppTheme.Agent 原值。原型中「立即同步」按钮演示的是状态流转，不是真实同步请求；「更新已是最新」等文案为状态位示意。原型数值不代表生产指标或性能基准。
